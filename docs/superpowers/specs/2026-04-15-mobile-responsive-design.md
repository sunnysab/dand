# 全站手机端响应式样式设计

**目标**

在不改变站点整体视觉语言的前提下，为全站模板补齐手机端响应式样式，让首页、分类页、归档页、文章页以及页头/页脚/阅读设置在窄屏设备上可读、稳定且不出现横向溢出。

## 现状

- `template/layout/base.html` 已包含 viewport meta，可直接使用响应式 CSS
- `template/asset/css/main.css` 已覆盖全站框架、列表页、页头页脚，并带少量窄屏规则
- `template/asset/css/post.css` 已覆盖文章页、正文内容与阅读设置面板，但主要按桌面阅读宽度设计
- 当前没有客户端识别或按设备切换 CSS 的机制

## 决策

### 样式组织

继续沿用现有样式文件：

- `template/asset/css/main.css`
- `template/asset/css/post.css`

不新增 `mobile.css`，也不做 UA / client 检测。

原因：

- 静态站点没有必要按设备动态分发样式
- 现有样式边界已经较清晰：全站框架与文章页分离
- 在原文件内补响应式断点，维护成本最低，且最容易保持桌面端风格一致

### 视觉方向

手机端采用“保守阅读型”方案：

- 延续现有配色、阴影、边框和排版基调
- 不引入新的卡片化布局或显著的视觉重设计
- 重点解决窄屏阅读舒适度、点击可达性和内容溢出问题

### 断点策略

采用三档响应式断点：

- `@media (max-width: 900px)`：平板与小桌面过渡
- `@media (max-width: 640px)`：手机主断点
- `@media (max-width: 420px)`：小屏手机微调

原因：

- 断点数量足够覆盖当前模板需求
- 能避免规则过碎，降低维护复杂度

## 范围

### 本次处理

- 页头在窄屏下的堆叠、换行和触达区域
- 首页、分类页、归档页的标题、间距和列表项排布
- 页脚在手机端的间距与对齐
- 文章页标题区、元信息区和正文区的窄屏排版
- 图片、代码块、表格、引用块等内容元素的手机端适配
- 阅读设置按钮与设置面板在手机端的尺寸、位置和宽度

### 本次不处理

- 汉堡菜单或导航结构重做
- 阅读设置交互逻辑重写
- 页面模板结构大改
- 深色模式、主题切换等新功能

## 实现方案

### 1. `main.css`：全站框架与列表页

调整方向：

- 让 `body` 在窄屏下使用更稳定的左右留白，避免桌面宽度规则挤压内容
- 保持 header 现有风格，仅在手机端优化纵向排列、导航换行和点击区域
- 让列表页标题层级、页头间距在窄屏下自然收缩
- 让 `listing-list` 项目在手机端改为上下排布，避免标题与日期/数量互相挤压
- 让 footer 在窄屏下保持清晰对齐与较小视觉负担

### 2. `post.css`：文章阅读体验

调整方向：

- 根据断点缩小文章容器外边距、标题字号和正文基础字号
- 维持当前阅读气质，避免把正文压得过密
- 允许分类、标签区自然换行
- 保证图片、代码块、表格只在局部滚动，不把整页撑出横向滚动
- 在手机端收紧 blockquote、code、pre、table 的内边距与圆角

### 3. 阅读设置浮层

调整方向：

- 缩小手机端浮动按钮尺寸与偏移量
- 保持当前半透明、轻阴影视觉风格
- 限制面板宽度，使其始终落在视口安全区内
- 在超小屏设备上减少与正文末尾、系统手势区的冲突

## 文件变更范围

### 主要修改

- `template/asset/css/main.css`
- `template/asset/css/post.css`

### 预期不修改

- `template/layout/base.html`
- `template/layout/site_header.html`
- `template/layout/site_footer.html`
- `template/page/index.html`
- `template/page/archive_list.html`
- `template/page/post.html`

只有在验证阶段确认仅靠 CSS 无法稳定解决交互或布局问题时，才考虑最小化调整模板。

## 风险与兼容性

- 现有桌面样式与新增断点规则可能产生覆盖顺序问题，需要把窄屏规则集中管理
- 文章页已有阅读设置自定义变量，移动端默认值的调整需避免与前端脚本冲突
- 表格与代码块的局部滚动需要验证不会影响正文整体横向稳定性

## 验证

### 自动验证

- `cargo build`
- `cargo test`

### 手动验证

生成站点后至少检查以下视口：

- `390x844`
- `430x932`
- `768x1024`

重点确认：

- 页面无横向滚动
- 页头与导航不拥挤
- 列表页信息层级清晰
- 正文、图片、代码块、表格不溢出
- 阅读设置按钮与面板可操作且不明显遮挡内容
